# Guía de Prácticas #04 - Gráfica de Árboles

## Descripción

Este proyecto implementa árboles binarios de búsqueda utilizando Python.

El programa permite insertar datos, realizar búsquedas y obtener los recorridos
preorden, inorden y postorden.

También genera una representación gráfica de los árboles utilizando Matplotlib.

## Requisitos

- Python 3
- Matplotlib

## Ejecución

Para ejecutar el programa se utiliza:

python arboles.py

## Estructura

- arboles.py: código principal del proyecto.
- datos/arboles.txt: datos utilizados para construir los árboles.
- capturas/: imágenes generadas por el programa.
